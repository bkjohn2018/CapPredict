# CapPredict Charter

**Purpose.** Forecast capital project cash curves using S-curve–aware features + ensemble ML to improve accruals, scenario planning, and schedule risk visibility.

**Scope.**
- Inputs: project attributes, timeline features, historical cash flow, engineered S-curve terms.
- Outputs: monthly capex forecast, confidence bands, explainability artifacts.

**Stakeholders.** Finance & Accounting, Project Controls, FP&A, Data/IT.

**Success Metrics.**
- ≤10–15% MAPE on holdout projects
- Cycle time reduction for monthly forecast
- Adoption in F&A workflow

**Governance (DLGI).** Ownership, literacy, right-sized controls; reproducible pipeline; documented lineage.
